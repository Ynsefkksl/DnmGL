# DnmGL

**DnmGL** is a simple-to-use RHI (Render Hardware Interface) designed to replace OpenGL in my personal projects. It aims to provide the power of modern graphics APIs with a simplified abstraction layer.

> [!CAUTION]
> **Project Status:** This project is in its very early stages and is **not yet ready** for use in external or production projects.

## Features

* **Backends:** Vulkan 1.1, Direct3D 12.
* **Shader Language:** Slang.
* **Design Goal:** A straightforward alternative to OpenGL for modern hardware.

## Supported Platforms

* **Windows**
* **Linux**
* **Android**

## Planned Features
* **Metal 3 Support For Apple Devices**
* **Mesh Shader Support**
* **Ray Tracing Support**
